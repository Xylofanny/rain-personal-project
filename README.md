# Rain Personal Project

This project is concerned with measuring the average daily precipitation of Kent, Washington from the years 2000 to 2025 using Open-Meteo API as the data source. The files are coded in Python and can take some time to load if multiple queries are given to the API.

## Research Questions
What are the wettest and driest months in Kent over the years?

Has Kent's precipitation in millimeters changed at all from 2000-2025?
